# pizza-sales-sql-analysis
SQL based analysis of pizza sales data with business insights


# Project Overview
This project analyzes pizza sales data using SQL to extract meaningful business insights related to sales performance, customer demand, and revenue trends.

The analysis is based on 21,350 orders, generating ₹817,860 in total revenue.

#  Objectives
- Analyze overall sales performance
- Identify top-selling and high-revenue pizzas
- Understand customer ordering patterns
- Perform category-wise and time-based analysis

# Tools & Technologies
- SQL
- MySQL Workbench

# Key Features
- Total Orders
- Total Revenue
- Most Ordered Pizza Size
- Top-Selling Pizzas
- Revenue by Category
- Peak Order Hours
- Cumulative Revenue Trend

# Project Structure
- sql_queries – SQL queries used for analysis
- presentation – Project PPT
- dataset – Dataset used for analysis
